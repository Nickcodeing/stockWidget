# Stock Widget · A 股 / 美股桌面悬浮行情

Windows 桌面置顶悬浮窗，用来看自选股的名称、现价、涨跌幅，以及对应大盘分时。标题处可在 **A股 / 美股** 之间切换，两套市场共用同一套界面。基于 Electron，无边框、半透明。默认可以点、可以拖；需要不挡下面窗口时，再在托盘勾选鼠标穿透。

行情默认来自**东方财富**，也可在窗口右上角或托盘菜单切换为**腾讯财经**、**新浪财经**。连续多次拿不到数据时，窗口会提示你换一个来源。**当前市场开盘时**约每 5 秒刷新；休市、午休、周末不再请求。启动、切换市场或重载配置时仍会拉一次，用来显示收盘价。

## 功能

- 标题 **A股 / 美股** 切换，当前市场会写入 `stocks.json` 的 `market`
- 自选股列表：名称 / 现价 / 涨跌幅，最多同时显示 3 行，可用滚轮查看其余股票。名称后跟小号代码，例如 `苹果 AAPL`、`寒武纪 688256`
- 底部指数可在 `stocks.json` 配置：A 股默认上证，美股默认纳斯达克100
- 当日分时图（黄线均价）。A 股红涨绿跌，美股绿涨红跌
- 左键点某只股票，切换其分时；默认显示当前市场的指数
- 右键自选行：置顶 / 上移 / 下移，顺序写回对应列表（指数行不能调）
- 悬停即可拖动窗口，点击与拖动自动区分
- 默认可点、可拖。托盘可勾选鼠标穿透，勾上后平时不挡下面的窗口，鼠标移到插件上时再暂时可操作
- 太阳 / 月亮两套主题
- 标题旁实时时钟
- 数据来源可切换：东方财富（默认）/ 腾讯财经 / 新浪财经。窗口右上角显示当前来源，托盘右键也可改。连续没有行情时会提示切换
- 系统托盘：显示 / 隐藏 / 退出
- 记住窗口位置（本地 `position.json`，不提交到 Git）
- 开盘才定时刷新：A 股（北京时间工作日 9:15–11:30、13:00–15:00），美股（纽约时间工作日 9:30–16:00，已考虑夏令时）。刚收盘会再拉一次，之后停刷
- 单实例：重复启动会唤起已有窗口，而不是再开一个

## 环境

- Windows 10 / 11
- [Node.js](https://nodejs.org/) LTS（用于安装依赖）

## 安装

在项目目录执行：

```bat
npm install
```

会下载 Electron 到 `node_modules`，体积较大，属正常现象。

## 启动

推荐双击 `启动.vbs`（无黑色命令行窗口）。

也可以：

- 双击 `启动.bat`
- 或在本目录执行 `npm start`

关闭请用托盘图标右键 **退出**。只关窗口或点任务栏，进程可能还在。左键托盘可切换显示 / 隐藏。

改代码后如果界面没变，多半是旧进程还占着单实例锁：先托盘退出，再重新启动。

## 配置

自选股和部分选项写在本机的 `stocks.json`。这个文件只留在你电脑上，**不会提交到 GitHub**。仓库里只有模板 `stocks.example.json`；如果本地还没有 `stocks.json`，启动时会自动复制一份。

```json
{
  "refreshIntervalMs": 5000,
  "opacity": 0.88,
  "clickThrough": false,
  "theme": "sun",
  "market": "cn",
  "quoteProvider": "eastmoney",
  "cnIndex": {
    "secId": "1.000001",
    "name": "上证指数"
  },
  "usIndex": {
    "secId": "100.NDX100",
    "name": "纳斯达克100"
  },
  "stocks": [
    { "code": "600519", "cost": 1680 },
    { "code": "000001", "cost": 0 },
    { "code": "300750", "cost": 0 },
    { "code": "601318", "cost": 0 },
    { "code": "000858", "cost": 0 },
    { "code": "002594", "cost": 0 }
  ],
  "usStocks": [
    { "code": "AAPL", "cost": 0 },
    { "code": "NVDA", "cost": 120.5 },
    { "code": "TSLA", "cost": 0 },
    { "code": "MSFT", "cost": 0 },
    { "code": "GOOGL", "cost": 0 },
    { "code": "AMZN", "cost": 0 }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `market` | 当前市场：`cn` 为 A 股，`us` 为美股。也可在窗口标题点击切换 |
| `quoteProvider` | 行情来源：`eastmoney` 东方财富（默认），`tencent` 腾讯财经，`sina` 新浪财经。也可在窗口或托盘切换 |
| `cnIndex` | A 股底栏指数。至少写 `secId`（东方财富代码）。`name` 可省略，不写则用接口返回的名称 |
| `usIndex` | 美股底栏指数，格式同上。默认 `"100.NDX100"`（纳斯达克100）。东财的 `"100.NDX"` 实际是纳斯达克综合指数，不要和 100 搞混 |
| `stocks` | A 股自选。每项 `{ "code": "600519", "cost": 0 }`。`code` 为 6 位代码，`6` 开头按沪市处理，其余按深市 |
| `usStocks` | 美股自选，格式同上，如 `{ "code": "AAPL", "cost": 0 }`。纽交所 / 纳斯达克会自动识别 |
| `code` | 股票代码 |
| `cost` | 成本价，改这个数字即可。默认 `0` 表示未设置，窗口不显示；大于 0 时在现价下方显示 `成本 14.34(+0.85%)`，括号内为相对成本的盈亏。今日涨跌仍相对昨收。指数行不显示成本 |
| `refreshIntervalMs` | 开盘时的行情刷新间隔，毫秒。休市不生效 |
| `opacity` | 窗口透明度 |
| `clickThrough` | 是否鼠标穿透。默认 `false`（可交互，方便拖动）。需要不挡下层窗口时再设为 `true`，或在托盘勾选 |
| `theme` | `sun` 浅色玻璃，`moon` 更深底色。也可在窗口里点太阳 / 月亮按钮切换 |

改完配置后，可用 `Ctrl+Shift+R` 重新加载，不必重启。

底栏指数用东方财富 `secId`。A 股常见：`1.000001` 上证、`0.399001` 深证成指、`1.000300` 沪深300。美股常见：`100.NDX100` 纳斯达克100、`100.NDX` 纳斯达克综合（东财代码叫 NDX，国际代码是 IXIC）。不要把深市 `000001` 当成上证。  
美股分时时段按北京时间约为 `21:30-04:00`（冬令时约为 `22:30-05:00`）。  
刷新只看**当前标题选中的市场**是否开盘，不处理节假日停牌（节假日若落在工作日时段仍会刷）。

## 操作

| 操作 | 作用 |
|------|------|
| 标题 A股 / 美股 | 切换市场 |
| 悬停后拖动 | 移动窗口 |
| 滚轮 | 列表超过 3 行时滚动 |
| 左键股票 | 切换分时 |
| 右键股票 | 置顶 / 上移 / 下移 |
| 太阳 / 月亮按钮 | 切换主题 |
| 右上角 东财 / 腾讯 / 新浪 | 切换行情数据来源 |
| `Ctrl+Shift+T` | 切换穿透 / 可交互 |
| `Ctrl+Shift+R` | 重新加载 `stocks.json` |
| 托盘左键 | 显示或隐藏 |
| 托盘右键 | 数据来源、鼠标穿透勾选、退出 |

未打包运行时支持开发热更新：保存 `renderer/` 会刷新窗口；保存 `main.js` / `preload.js` 会自动重启；保存 `stocks.json` 会重载配置。打成 exe 后不会监听文件。

## 目录说明

```
stock-widget/
├── main.js          主进程：窗口、托盘、行情、分时、位置记忆
├── preload.js       渲染进程安全桥接
├── lib/             东方财富 / 腾讯 / 新浪行情适配
├── stocks.example.json  自选股模板（可提交）
├── stocks.json      本机自选与选项（已忽略，不上传）
├── icon.png         托盘图标
├── 启动.vbs         无黑窗启动
├── 启动.bat         命令行启动
└── renderer/        界面：列表、时钟、分时 canvas
```

`stocks.json` 和 `position.json` 只在本机使用，已加入 `.gitignore`，不会上传到 GitHub。

## 打包（可选）

```bat
npm run dist
```

会打出 Windows 便携 exe。未签名时，别人电脑上可能被 SmartScreen 拦截。也可以把整个项目（含已安装的 `node_modules`）拷走使用，体积会很大。

## 说明

- 仅供个人看盘，数据以来源网站公开接口为准，不构成投资建议。查不到的股票该行显示 `--`，列表末尾会提示「部分数据未查询到」；没有分时就显示暂无分时，不会改用其他来源
- 东方财富实时接口不通时会自动改走其延迟行情接口；若整家都没数据，请手动换成腾讯或新浪
- 运行时大约会有多个 Electron 进程，内存占用高于普通小工具，属 Electron 常态
- `启动.vbs` 隐藏控制台，崩溃时看不到报错；排查可改用 `npm start`
